# Автоматизация сбора обратной связи по  сотрудникам для руководителей 
#### Сервис автоматического сбора анонимной обратной связи по сотрудникам для руководителей
#### Система собирает данные о взаимодействии сотрудников из корпоративных систем, предлагает оставить анонимную оценку, показывает руководителю динамику на дашборде и начисляет бонусы за участие.
